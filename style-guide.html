Principles

Calm, typographic and exact. The data is the only thing allowed to be loud.

  • One accent. A single blue carries links, the current page and focus. Everything else is ink on paper.
  • Color has a job. Categorical color is identity, sequential is magnitude, diverging is polarity, status is state. Never decoration.
  • Every number is dated and tagged with a provenance badge and a source.
  • Every chart has a table. Tooltips help; they never gate a value.
  • Two themes, both designed. Dark is its own palette, not an inversion. Check both.

Color tokens

All colors are CSS custom properties on :root, redefined for dark mode. Charts read them at render time, so the theme toggle re-colors every chart. Swatches below follow the current theme.

Series take slots in this order. To keep an entity the same color across charts, pin it with "color": 3 on the series. A ninth series is never a new hue: fold it into "Other". Scatter and bubble charts use at most 3 series.

Sequential and diverging

Sequential (--seq-1 to --seq-10) shows magnitude. Diverging (--div-pos-*, --div-mid, --div-neg-*) shows polarity: waterfall increases are --div-pos-2, decreases --div-neg-2, totals neutral --c-total.

Status (only for status)

On track Watch Tight Risk

Always icon + label; never color alone and never as a chart series. Markup: <span class="status status--warning">Watch</span>.

Typography

System fonts only, no web fonts. A system serif (Iowan Old Style, Charter, Cambria, Georgia) for titles and long-form prose; the system sans for UI, tables, numbers and charts. Big numbers use proportional figures; columns of numbers use tabular-nums.

Layout

The shell has a sticky left sidebar (built from nav.js), a main column, and an "On this page" rail generated from every h2/h3 on screens 1280px and wider. Below 1024px the sidebar becomes a drawer behind the menu button.

Inside .article, every child sits in the reading column. Two opt-outs:

.wide: charts, tables, card grids, KPI rows. Breaks out of the reading column on large screens.
(default): prose, callouts, small figures. Holds a ~72ch measure.

Use .full for rare edge-to-edge bands (add .full-inner inside for gutters). Wrap each h2 section in a plain <section>; it inherits the grid.

Provenance badges

Place right after the number: $230bn <span class="prov" data-prov="E">E</span>. Hover or focus shows the meaning; screen readers get it as text. In charts use "provenance" in the JSON.

Citations and sources

Revenue grew tenfold in four years.1 Hover the number to preview the source.

  1. Publisher, “Title of the document”, 2026-06-30, example.com

Cite with <a class="cite" href="#src-1">1</a> (the brackets are drawn by CSS). Each source is <li id="src-1"> in <ol class="sources">, numbered as in the dossier.

Glossary terms

Accelerators need HBM and advanced packaging. An ASIC can also use a plain <abbr>. Inline definitions work too: TFLOPS.

<span class="term" data-term="HBM">HBM</span> looks the definition up in the page's <script type="application/json" id="atlas-glossary"> block (or window.ATLAS_GLOSSARY); data-def="…" defines it inline. Use on first mention per section only.

Charts

Every chart is a <figure> holding an inline <script type="application/json" data-chart> config. atlas.js draws an SVG, a legend (for 2+ series), a tooltip, a keyboard-navigable focus layer (arrow keys), a Table toggle and a source line. Charts re-render on resize and on theme change. Open "Show config" under any chart to copy it.

Rules

  • One value axis. Never a dual axis; use two charts.
  • No pie charts: use a bar or a treemap.
  • Text is always ink; identity comes from the swatch beside it.
  • Always set source, asOf and provenance.
